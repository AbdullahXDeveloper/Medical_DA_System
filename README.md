# 🏥 Hospital Data Analytics System

## 📌 Overview
A NumPy-based data analysis project for analyzing patient health data.

## 🚀 Features
- Patient statistics analysis
- High-risk detection system
- Age group health analysis
- Data visualization using Matplotlib

## 🧠 Tech Used
- Python
- NumPy
- Matplotlib

## 📊 Visualizations
- Blood pressure distribution
- Age vs Sugar levels
- Cholesterol comparison

## ⚙️ How to Run

```bash
pip install -r requirements.txt
python src/main.py
